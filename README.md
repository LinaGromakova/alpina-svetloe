# Alpina Svetloe 
🔗 **[Посмотреть работающий проект](https://www.alpina-svetloe.ru/)** 
[![Deploy with Vercel](https://vercel.com)](https://alpina-svetloe.vercel.app/)

**Alpina Svetloe** — это современный, высокопроизводительный сайт-визитка (лендинг) с плавным скроллом и интерактивными анимациями. Проект разработан с акцентом на максимальную оптимизацию и гибкую, расширяемую архитектуру, готовую к будущему масштабированию.

##  Ключевые особенности

* **Плавный скролл (Lenis Scroll)** — интеграция облегченного ядра Lenis для идеальной плавности без ущерба производительности.
* **Интерактивные анимации** — динамичный и отзывчивый интерфейс на базе Framer Motion.
* **Экстремальная оптимизация** — глубокая компрессия графических ресурсов для мгновенной загрузки страниц.
* **Масштабируемая архитектура** — чистая модульная структура кода, созданная под легкую интеграцию CMS или превращение лендинга в многофункциональное веб-приложение.

##  Стек технологий

* **Vite** — быстрая сборка и моментальный Hot Module Replacement (HMR).
* **React** — компонентный подход и декларативный UI.
* **Framer Motion** — сложная, но легковесная декларативная анимация.
* **Lenis (Core)** — минимизированное ядро библиотеки для ультра-плавного скролла.

##  Архитектурные решения

Проект построен по **модульному принципу**. Это минимизирует затраты на долгосрочную поддержку и позволяет:
1. Легко подключить любую headless CMS (Strapi, Contentful, Sanity).
2. Наращивать бизнес-логику без переписывания существующего функционала.
3. Быстро кастомизировать отдельные блоки интерфейса.
